Assignment Overview:

Overall, the purpose of this assignment - as far as I've come to understand it that is - is to get really familiar
with most of the important concepts that you when utilizing Object-Oriented Programming. Like inheritance, polymorphism,
interfaces, and abstract classes (as said so by the first sentence of the assignment description). Essentially, the
assignment does this by tasking you to 'pull' as many shared details up into a parent class as possible, and try to
reuse those elements across as many subclasses as possible. So that each subclass only has to worry about their own
unique behaviours.
